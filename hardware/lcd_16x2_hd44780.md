# 16×2 LCD (HD44780-Compatible)

## Overview

A 16-column × 2-row character LCD display built around the Hitachi HD44780 controller (or a compatible clone). It displays ASCII characters and a small set of Japanese katakana, and supports up to 8 user-defined custom characters stored in CGRAM. Widely used with the Arduino `LiquidCrystal` library.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| Display format | 16 characters × 2 rows |
| Controller | HD44780 (or compatible) |
| Character size | 5×8 dot matrix |
| Operating voltage | 5V |
| Interface | 4-bit or 8-bit parallel |
| Backlight | LED (typically 5V, via current-limiting resistor) |
| Contrast adjust | Analog voltage on V0 pin (via potentiometer) |

## Pin Reference

| Pin | Label | Description |
|-----|-------|-------------|
| 1 | VSS | Ground |
| 2 | VDD | 5V power |
| 3 | V0 | Contrast adjust (0–5V via potentiometer) |
| 4 | RS | Register Select: LOW = command, HIGH = data |
| 5 | RW | Read/Write: tie to GND for write-only use |
| 6 | E | Enable (clock) |
| 7–10 | D0–D3 | Data bits (not used in 4-bit mode) |
| 11–14 | D4–D7 | Data bits |
| 15 | LED+ | Backlight anode (5V via 220 Ω resistor) |
| 16 | LED− | Backlight cathode (GND) |

## Arduino Usage

Use the built-in `LiquidCrystal` library in 4-bit mode — only pins D4–D7 plus RS and E are needed, saving 4 Arduino pins.

```cpp
#include <LiquidCrystal.h>
// LiquidCrystal(rs, enable, d4, d5, d6, d7)
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  lcd.begin(16, 2);
  lcd.print("Hello, world!");
}
```

## Notes

- Tie RW (pin 5) to GND for write-only operation; this is the standard approach since the library never reads from the display.
- The V0 contrast pin is very sensitive — connect it to the center wiper of a 10 kΩ potentiometer between 5V and GND.
- The backlight LED draws ~20–40 mA; always use a current-limiting resistor (220 Ω is typical at 5V).
- `lcd.clear()` takes ~2 ms. Avoid calling it in tight loops — instead overwrite characters with spaces where possible.
